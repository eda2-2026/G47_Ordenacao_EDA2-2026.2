## Sobre o Projeto

O Organizador de Despesas Pessoais é um sistema desenvolvido em Python com o objetivo de organizar despesas financeiras por meio de algoritmos de ordenação.

A aplicação permite organizar despesas de acordo com critérios como valor e descrição, facilitando a visualização e a análise dos gastos pessoais.

## Objetivos

- Aplicar conceitos de Estruturas de Dados 2.
- Implementar algoritmos de ordenação em Python.
- Organizar despesas pessoais de acordo com diferentes critérios.
- Analisar e comparar o funcionamento e o desempenho dos algoritmos implementados.

## Algoritmos de Ordenação

Os algoritmos utilizados no projeto serão documentados nesta seção conforme forem implementados.

- **Bubble Sort:** ordenação por meio de comparações e trocas entre elementos adjacentes.
- **Merge Sort:** ordenação baseada na divisão da lista em partes menores e posterior combinação dos elementos ordenados.
